# NEU Dot 使用与开发指南

本文对应 **0.7.9**。[返回项目首页](../README.md) · [下载最新版](https://github.com/yzbcs/NEU-Dot/releases/latest)

## 安装与首次使用

在 [最新版发布页](https://github.com/yzbcs/NEU-Dot/releases/latest) 选择 Apple Silicon Mac 的 DMG 或 Windows x64 安装程序。Mac 将应用拖入“应用程序”后打开。Windows 按安装程序选择安装目录。0.7.6 及更早版本升级时，需要从系统托盘退出旧应用，再运行最新版安装程序，沿用原安装目录及安装范围。安装 0.7.7 后可通过应用内更新升级后续版本。应用从当前 Windows 用户的 `%APPDATA%\NEU Dola` 读取工作台数据，更新前可复制该目录备份。

Mac 与 Windows 安装包均已生成，但尚未签名，系统可能提示无法验证发布者；Windows 尚未实机运行。遇到问题时，可在仓库 [Issues](https://github.com/yzbcs/NEU-Dot/issues) 提供系统版本、应用版本和复现步骤。

首次打开先选择本科生或研究生，再进入“工作台首页”。这一选择统一用于课表网页导入、校园服务与 AI 助手的身份上下文，可在“设置 → 学生类型”修改。旧版用户升级后也需确认一次，已有课表、笔记、待办与资料保留。课表、待办和笔记可直接使用，AI 与邮箱按需配置。应用加载失败时，启动页会显示原因并提供重试按钮。

## 设置总览

侧栏“设置”先显示当前配置，再进入具体项目。页面按四组排列，共十个入口：

| 分组       | 项目                                |
| ---------- | ----------------------------------- |
| 通用       | 外观、学生类型                      |
| 模型与连接 | 模型服务、邮箱账号、本地资料        |
| 学习与提醒 | 学期与节次、提醒与后台              |
| 数据与帮助 | 本地数据、帮助与诊断、关于 NEU Dot |

外观与侧栏的主题入口共用同一份设置。“学生类型”统一修改本科生、研究生选择，课表导入与校园入口同步生效，AI 后续提问使用新的身份上下文。本地资料入口打开已有文件工作区；“关于”显示实际运行的应用版本。

模型服务和邮箱账号先显示列表，点击“编辑”再修改。**保存与测试连接分开**：保存只保留填写的配置，测试使用当前表单发起连接，不保存修改。测试模型会发送一条简短请求，可能消耗所选服务额度；邮箱测试验证 IMAP 与 SMTP 连接，不收取或发送邮件。测试通过后，仍需点击保存才能保留修改。编辑已有连接时，密钥或授权码留空可复用原值；更换服务地址、邮箱服务器或用户名时，按界面提示重新填写。

聊天中的“模型设置”会定位该聊天使用的服务，并提供返回原对话的入口；未发送草稿保留。更改配置不会自动发送聊天消息。

“学期与节次”可单独修改学期名称、第一周周一及 12 节上课时间，保存时保留现有课程与导入来源。改变首周日期或节次时间会改变课程对应的日期或显示时间，请按实际学期填写。

“提醒与后台”集中说明运行条件并提供测试提醒。每条待办的提醒时间和重复规则仍在待办中编辑；测试提示已请求系统通知，不代表系统横幅一定送达。

## 首页与待办

“接下来”优先显示正在进行的课程，否则显示未来七天最近的课程或定时待办。点击即可打开对应记录。

未来七天安排按日期合并课程与待办，今天的课程会标注待上课、上课中或已结束。逾期待办和未设时间的待办单独显示；重复事项展示当前保存的下一次时间。

可以在首页新建、完成或恢复待办。“今日便利贴”提供完整管理，支持四色、定时提醒、每天/工作日/每周重复及推迟提醒。

- 勾选后立即保存完成状态，卡片暂留原位；再次点击可恢复。
- 点击“收起已完成”或离开页面后，列表会整理；普通完成项可在“已完成”中查看和恢复。
- 重复事项显示本次完成状态与下次时间；本次查看中撤销完成，可恢复原提醒时间。
- 点击待办通知会打开应用并定位到记录，便于继续编辑、推迟或完成。

提醒时间按北京时间处理。关闭窗口后应用保留托盘后台运行，**退出应用或电脑关机后不运行提醒**。在“今日便利贴”点击“测试提醒”，可检查通知权限和系统勿扰设置。

## 导入与使用课表

### 网页导入

1. 在“我的课表”点击“本科生网页导入”或“研究生网页导入”，打开与全局学生类型对应的学校系统窗口。若类型不符，先到“设置 → 学生类型”修改。
2. 自行完成学校统一认证，进入个人课表并选择全学期。
3. 点击右上角“读取当前课表”。应用只读取当前展示的课程；分页列表应先选择显示全部。
4. 核对课程、星期、节次、周次、地点、学期与第一周周一，再保存。

导入窗口的登录状态与日常浏览器分开，无需把学校密码填入 NEU Dot 设置。读取结果不会自动发送给 AI；后续向模型提问时，相关课程信息可能作为回答上下文发送给模型服务。

本科入口为 `jwxt.neu.edu.cn`，研究生入口为 `yjs.neu.edu.cn`，两类导入会话分开保存。根据[学校教务处通知](https://aao.neu.edu.cn/2026/0227/c9405a450413/page.htm)，本科系统在非校园网环境下需要通过学校 WebVPN 或 OpenVPN 访问；当前应用内直接读取本科入口，尚未验证 WebVPN 代理后的课表读取。若登录后“选择身份”为空，请先核对学生类型和学校账号权限；加载失败会在顶部显示网络提示。

研究生已有真实网页样例验证；本科入口切换、读取和保存已使用人工学校页面验证，真实本科课表版式仍待补充。

### PDF 与手动录入

可以导入本机课表 PDF，预览并修正后保存；扫描 PDF 和未识别的版式可手动录入。现有导入验证覆盖研究生网页与文本 PDF 样例，本科课表版式仍待补充。

若固定解析没有识别出课程，页面会显示“交给 AI 识别此 PDF”。点击后原文件和导入请求会进入 AI 输入框，发送后由所选模型读取。也可以点击课表页的“AI 导入”，再在聊天中添加文件。AI 返回“课表导入草稿”卡后，点击“预览并保存课表”，核对课程、周次、学期与首周日期，再确认保存。确认保存整表会替换当前课表，预览中有对应提示。

星期或节次无法准确识别的课程可列为“待确认”，草稿卡会显示数量，预览中列出具体原因。保存前请核对原文件中这些安排。

课表支持单双周、自定义 12 节时间、按课程配色的周视图、时间冲突提示和 ICS 日历导出。相同课程在切周或切换主题后使用一致色系。请正确设置第一周周一，以便课程落在对应日期。

点击课程可核对时间与地点，也可新建本次课堂笔记：笔记填入课程信息，并归入以课程名称命名的笔记本。课程详情可打开同名分类的笔记与本地资料。

课表导入是读取与保存本机课程安排；当前没有接通成绩、考试、选课等其他个人教务数据。

## 笔记与本地资料

### 应用笔记

“资料与笔记 → 备忘录”采用笔记本、列表、正文三栏布局。支持新建或重命名笔记本、移动与置顶笔记、正文搜索、模板、格式工具栏、自动保存和导出。移除笔记本时，其中的笔记移入“未分类”。

清单在“阅读模式”下可点击圆圈完成或恢复。“问问 AI”会先保存笔记，再准备提问草稿；编辑并发送后才请求模型。

### 本地资料

“资料与笔记 → 本地资料”用于浏览电脑上已有的文件。点击“添加文件夹”选择课程、论文或项目目录，也可以用“添加文件”选择单个文件，或将 PDF、Markdown 文件拖入页面。文件保留在原位置，应用记录文件位置。

左侧按需展开文件夹，每次只读取所打开的这一层。点击 Markdown 文件，在右侧阅读排版后的正文；可切换“源码”查看原文，使用文内查找定位内容。文本与代码文件直接显示原文。外部编辑器改动文件后，点击刷新即可重新读取。

Markdown 中的本地相对图片会随正文显示，相对文档链接可继续打开已添加文件夹范围内的文件，标题链接可定位文内章节。单独添加 Markdown 后，需要添加包含链接目标或图片的文件夹，再访问这些相对文件。跨分类跳转会自动清除冲突的筛选条件。网络图片显示浏览器查看入口。文本和本地图片预览支持 8 MB 以内的文件。

PDF 可在应用内阅读，支持翻页、缩放和选中文字，单份文件最大支持 50 MB。主导航栏和资料目录可拖动调宽、折叠，并记住上次设置。文件工具栏提供用系统应用打开、在文件管理器中定位等操作，适用于 Word 等其他格式。文件被移动或删除时会显示提示，刷新或重新添加后继续使用。

选中文字后可创建四色高亮和批注，在标注面板编辑、删除或跳转到原文。标注独立保存在本机。原文件改变后，旧标注会提示位置可能变化。

阅读工具栏的“自动翻译”默认开启，选中的英文会发送给所选模型服务，可随时关闭。也可以手动翻译所选文字，在阅读助手中切换翻译服务。点击“AI 总结”可总结当前 PDF 或文本，单次最多读取 100 页 PDF、60,000 字原文，并显示实际读取范围。扫描 PDF 缺少文字层时，总结会提示先进行文字识别。

点击“询问资料”会准备包含当前文件位置的可编辑提问草稿，点击发送后调用模型。AI 对 Markdown、文本和代码按需读取，对带文字层的 PDF 按页提取文本。需要图片理解时，可通过聊天的“引用文件”选择材料，并使用支持图片输入的模型服务。

升级后新增的文件读取来源会在应用内定位到实际读取的文件；旧对话中没有子文件路径的来源仍打开原来的文件或目录。全局搜索命中的本地文件也在这里打开，文件夹结果进入对应目录；搜索范围仍是已添加资料的名称与路径，不会扫描整个硬盘。

## 配置与使用 AI

当前继续使用 Pi 1.5.0 管理 AI 会话。每个对话都提供工作台工具，按问题读取相关内容；11 个工具负责查询、读取、三种创建操作和课表导入草稿，三种模型接口继续支持。

### 连接模型服务

在“设置 → 模型服务”点击“添加模型服务”，或在已有服务旁点击“编辑”。选择接口类型，填写服务地址与 API Key，点击“获取模型”，选择模型后保存。支持：

| 接口               | 用途                               |
| ------------------ | ---------------------------------- |
| OpenAI Responses   | 使用支持 Responses API 的服务      |
| Chat Completions   | 使用兼容 Chat Completions 的服务   |
| Anthropic Messages | 使用支持 Anthropic Messages 的服务 |

聊天底部的供应商按钮与模型按钮分别选择服务和模型。点击 GLM、MiniMax 等供应商名称即可直接切换，模型列表只显示当前供应商的模型，并可搜索和刷新。来回切换会恢复各供应商刚选的模型。每个会话保留自己的当前模型选择。API Key 由使用者自行提供并在本机使用系统加密存储。工作台读取与保存需要所选模型及服务支持工具调用。

空白聊天提供“安排今天、整理课程笔记、查找学习资料”入口，点击后会准备可编辑的提问草稿，发送后才请求模型。

### 引用文件

输入框旁点击“引用文件”，可选择 PDF、PNG、JPEG、WebP，或 UTF-8 编码的文字、Markdown、CSV、JSON 和代码文件。每条消息最多引用 6 份文件，PDF 单份最多 50 MB，图片和文字单份最多 8 MB。添加后可打开核对或移除，再发送请求。

文件会在本机保存一份快照，发送后与该条消息关联。AI 按问题读取，回复中的文件来源可打开核对。PDF 按页读取，长文字按段读取。引用文件中的要求按资料处理，操作以你发送的请求为准。

应用默认允许向模型服务发送图片，旧版配置首次升级到 0.7.4 时也会开启。可在“模型设置 → 编辑服务”的“允许向此服务发送图片”中调整，之后手动关闭的选择会保存。截图、扫描页或需要核对表格布局时，实际选用的模型仍需支持图片理解。服务端若拒绝图片输入，会显示具体错误。

可以发送“从这份课表生成导入草稿”“把附件里的作业提取成待办”“把这份资料整理并保存成笔记”，也可以附上错误截图或日志询问功能问题。课表整表导入通过草稿预览确认，待办和笔记沿用现有创建工具及结果卡。

“资料与笔记”提供“AI 导入笔记”，“今日便利贴”提供“AI 导入便利贴”。这些入口会开始一份对应功能的提问草稿，包含读取原材料、核对已有记录、处理缺项、调用保存能力与核对结果的完整步骤。笔记保留 Markdown、代码和清单状态，便利贴明确使用北京时间、提醒条件与去重要求。进入新的功能接续任务时会更换输入框草稿及引用文件。

PDF 课表解析失败会带上原 PDF 与失败原因，网页课表解析失败会带上当前已展示表格的 JSON 快照。课表、笔记或便利贴模块的错误提示也提供“交给 AI 继续”，其提示词包含对应模块的读取和核对步骤。发送前可查看、编辑请求和引用文件。

对话附件与“本地资料”使用同一套 PDF、文字与图片读取逻辑。已发送的文件随聊天保留，删除聊天会清理仅由该聊天引用的附件。未发送附件可手动移除，启动时会清理未关联的副本。

### 读取工作台

每个对话都可按问题读取课表、待办、笔记、已添加的本地资料和已配置邮箱，无需先开启连接开关。相关内容会发送给当前选择的模型服务；普通问候、概念解释和不依赖工作台数据的问题可直接回答，不要求每次都查工具。

AI 可以按完成状态和北京时间日期筛选待办，按日期、周次与上课时间查询课程，搜索笔记并读取正文。发送工作台问题前会等待未完成的笔记保存。回复中的来源可以打开核对。

邮箱工具支持查询目录和读取邮件纯文本正文，**AI 不会发送邮件**。手动发信仍在邮箱界面完成。

### 创建记录与结果卡

可以明确要求：

- “帮我添加明天 20:00 的论文阅读提醒。”
- “把这些课程加入课表。”
- “把上面的内容保存成笔记。”

信息齐全的明确保存请求可以直接执行；缺少必要信息时先追问，普通建议不会自动保存。操作成功后，结果卡显示实际保存的记录，并提供查看、编辑与撤销入口。已在创建后编辑过的记录会保留，撤销不会直接删除它。

追加课程保留现有学期、节次、导入来源和原课程，跳过重复安排；如果出现重叠，结果卡标出冲突课程和周次。同一条回复中重复发出的等价创建请求复用已有结果。停止生成或模型续接失败时，已经成功保存的记录及结果卡仍会保留。

### AI 导入中的周次与记录状态

课表中同一课程的教师、地点或时间随周次变化时，AI 提示要求拆成独立安排并保留对应关系，也要求核对单双周、停课和补课。可以直接询问“第 9 周的课程分别由谁授课”，助手通过周次筛选工具获取对应记录。教师在课程详情中展示。

便利贴导入支持清单完成状态，已完成记录按历史状态保存。提醒时刻和截止时刻有不同要求时，助手会先核对处理方式。笔记导入按用户要求保留原文或保存整理稿，核对笔记本、同名记录、代码、表格和清单状态。读取或保存中断后，助手先核对已保存记录，再继续剩余内容。

### 对话记录与自动整理

对话标题在本地按主题与关键词提炼，通常不超过 14 个字符。新聊天在第一条消息发送时生成标题，旧版自动标题会结合已有用户消息整理，已有自定义标题继续沿用。继续聊天时保留当前标题，标题生成无需额外模型请求。

左侧对话记录按今天、昨天、近七天和更早分组，并按最近活动排序。搜索可匹配标题、消息正文和引用文件名称。记录显示供应商、消息数和引用文件数，悬停或键盘聚焦时显示删除入口。小窗口会收起底部的外观快捷栏，主题可在设置中调整。

新回合会在本机保存完整的工具调用与结果，后续对话继续使用这些记录。对话接近配置的上下文预算时，Pi 会自动整理较早内容并保留近期内容，界面显示“整理对话上下文”。自动整理会额外调用当前模型生成摘要，消耗相应服务额度。

旧聊天在升级后首次继续时导入已有消息和保存回执，无需手动重建；旧版本未保存的工具往返内容无法补回。删除聊天也会删除其关联的 Pi 会话记录，但不会撤销已经创建的待办、课程或笔记。

## 邮箱

在“设置 → 邮箱账号”添加或编辑账号，打开设置不会自动收信。邮箱页面支持学校云邮箱、QQ、163 和自定义 IMAP/SMTP，可查看文件夹、读信、下载附件、回复和发信。

邮箱通常需要客户端授权码。QQ 和 163 提供可编辑的主机预设；学校学生云邮箱请从网页邮箱设置确认 IMAP/SMTP 主机，不要直接套用教工邮箱参数。授权信息在本机使用系统加密存储。

## 搜索、外观与本机数据

侧栏“搜索工作台”或 `⌘/Ctrl + K` 可查询笔记正文、待办详情、课程信息、本地资料名称与路径、聊天记录。方向键选择结果，`Enter` 打开，`Escape` 关闭。搜索在本机执行，打开前会保存正在编辑的笔记；不会读取本地文件正文或下载邮件。

左下角“外观”支持浅色、深色与跟随系统，默认跟随系统；选择会在本机保存，重启后保留。界面动效跟随系统“减少动态效果”设置。

工作台数据和聊天记录保存在本机。“设置 → 本地数据”提供当前数据目录与打开入口，“设置 → 帮助与诊断”可查看和复制错误日志。AI 请求与邮箱功能分别连接使用者配置的外部服务，因此“本机保存”不等于所有功能都离线运行。

## 应用内更新

带更新功能的安装包会在启动约 10 秒后检查 GitHub Releases，运行期间每 6 小时再次检查。发现稳定版更新时显示侧栏提醒，并尝试发送系统通知。可以随时进入“设置 → 关于 NEU Dot”手动检查。

点击“下载更新”查看下载进度，支持取消和失败后重试。下载完成后点击“重启并安装”。重启前会保存笔记，进行中的操作和 AI 回复需要完成后再安装。应用的数据目录继续沿用原位置。

Windows 使用 NSIS 安装器完成升级。Mac 下载 ZIP 后校验 SHA-512、应用标识与版本，在退出后替换应用并重启，新版本未能打开工作台时恢复旧应用。Mac 应用应放在具有写入权限的应用目录，直接从只读 DMG 运行时需要先完成安装。

目前公开旧版需要先手动安装一次包含更新功能的新版，之后才能使用应用内更新。开发运行与网页演示显示更新不可用状态。检查失败时可以通过关于页的“查看更新记录”访问发布页。

使用 Node.js 24.22.1（见 [.node-version](../.node-version)，项目要求 Node.js ≥ 24）。

```sh
npm ci
npm run dev
```

### 常用命令

| 命令                  | 作用                         |
| --------------------- | ---------------------------- |
| `npm run typecheck`   | TypeScript 类型检查          |
| `npm run build`       | 类型检查与生产构建           |
| `npm run package:mac` | 构建 Apple Silicon Mac DMG   |
| `npm run package:win` | 构建 Windows x64 NSIS 安装包 |

### 代码位置

| 目录           | 内容                                        |
| -------------- | ------------------------------------------- |
| `src/main`     | Electron 主进程、模型服务、工作台存储与邮箱 |
| `src/renderer` | React 界面                                  |
| `src/shared`   | 共享类型、工作台模型与校验                  |
| `website`      | 官网与功能演示                              |
| `scripts`      | 官网构建入口                                |
| `assets`       | 应用图标与公开截图                          |

打包产物默认位于 `assets/output/releases`。项目使用 Electron、React 和 TypeScript，依赖及脚本以 [package.json](../package.json) 为准。
