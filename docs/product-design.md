## 产品判断

个人助手的首页应先回答“接下来做什么”。0.3.7 的功能已经互通，但大统计卡、七天日程和重复的今日课程抢占同一层级。邮箱账号数和笔记总数有入口价值，优先级低于下一门课、下一件待办。

这轮把界面整理为：

1. **接下来**：今天正在进行的课程优先；没有当前课程时，展示未来七天最近的课程或定时待办。直接打开对应记录。未设置学期时显示导入引导，不能解释成没有课程。
2. **紧凑概览**：保留待办、今日课程、笔记、邮箱的真实数量和跳转，缩小卡片高度。
3. **安排与行动**：宽窗口中，唯一的七天课程时间线和可以直接完成、恢复的待办并排；窄窗口按顺序堆叠。课程时间线保留课程色标、待上课、上课中和已结束状态。
4. **继续记录**：最近笔记和常用入口放在下方；不再重复整张今日课程表。

聊天空白页改用“安排今天、整理课程笔记、查找学习资料”三个具体场景。未配置模型时先展示连接入口；点击场景只准备草稿并开启工作台读取，用户发送后才请求模型。保留编辑草稿的机会。

## 0.4.0：明确请求与真实保存结果

聊天支持创建待办、追加课程和保存笔记。用户明确说“帮我添加”“加入课表”“保存成笔记”，且必要信息完整时直接执行；缺少必要信息先追问。一般建议和拟定方案不自动保存。聊天中的“工作台已连接”说明同时包含读取与按指令创建，关闭后不提供这些工具。

保存结果以独立卡片显示在对应助手消息中。卡片内容来自本机执行回执：记录类型、标题、具体安排或正文摘要，以及查看、编辑、撤销入口。课程卡直接显示冲突课程名和周次；重复课程跳过。追加操作保留原课表、导入来源、节次与学期设置。

卡片在写入完成后立即保存，不等待模型总结。用户停止生成、模型续接失败或重启应用后，已经保存的结果仍然可见并可操作。同一条回复内等价的创建调用复用成功结果，避免重复保存。撤销只删除创建后未被编辑的记录；已编辑记录会保留，并告诉用户当前处理结果。

结果卡使用现有纸感面板和蓝绿配色，与普通回复保持清楚的层级。确认创建、提示冲突和显示撤销状态由文字与可用按钮表达；不能仅依赖颜色，流式回复更新也不使整张卡片重复入场。

## 0.4.0：启动状态与提醒后的操作

启动页沿用 D + 折页图标和 NEU-Dela 字标，说明正在加载工作台。数据就绪立即进入首页，不为展示品牌增加固定等待；加载失败显示原因和重试按钮。减少动态效果设置下保留状态文字与重试入口。

点击待办通知后显示主窗口，打开“今日便利贴”并定位到对应记录。用户可继续推迟提醒、完成或恢复，推迟后的时间保存为真实提醒时间。通知入口与日常待办页面使用同一份记录，避免只打开首页却找不到提醒对象。

系统通知横幅是否送达取决于系统权限、后台运行与勿扰设置。此次桌面检查验证与点击通知共用的导航处理，不将该结果写成横幅送达验证。

## 视觉系统

- 浅色页面 `#f2f1ed`，面板 `#faf9f6`，侧栏 `#e8ede9`。背景保持柔和的暖灰，不叠加影响文字阅读的颗粒图片。
- 深色页面 `#151f23`，面板 `#1e2b30`，侧栏 `#111c20`。继续使用对应的深色文字、输入框和边框。
- 主要操作使用蓝色，当前状态与完成反馈用青绿；课程沿用稳定配色。
- 侧栏收窄，导航选中状态使用底色、文字和左侧短线共同说明。保留最近对话的最小可用区域和底部设置；移除没有实际状态含义的固定绿色装饰点。
- 首页与聊天标题缩小，内容层级通过字号、间距和位置表达。控件保持键盘焦点轮廓。

## 动效

| 场景                                 | 行为                             | 时间          |
| ------------------------------------ | -------------------------------- | ------------- |
| 页面标题和聊天欢迎区进入             | 淡入并上移 4px                   | 180ms         |
| 弹窗                                 | 遮罩淡入，面板上移 8px、轻微缩放 | 120ms / 200ms |
| 模型等选择菜单                       | 淡入并上移 3px                   | 140ms         |
| 选中日期、导航、搜索结果             | 颜色过渡，少量图标位移           | 120–150ms     |
| 切换日程日期、完成提示、展开积压事项 | 内容淡入                         | 160ms         |

日程仅在切换日期时重新入场。聊天流式文本和整页容器保持稳定，不随每个 token 或每次保存反复动画。系统启用“减少动态效果”时，关闭动画、过渡和这些交互位移，状态、文字、勾选和焦点提示仍保留。

实现参考 [WebKit 对减少动态效果的说明](https://webkit.org/blog/7551/responsive-design-for-motion/)；整体身份与清晰度参考 [Apple 应用图标指南](https://developer.apple.com/design/human-interface-guidelines/app-icons)。这些原则用于指导取舍，不代表本应用获得平台认证。

子页先展示当前配置，点击“编辑”才进入表单。表单提供明确的保存和取消；保存成功后更新摘要，失败时保留输入并显示具体原因。复用现有设置、邮箱账号、资料关联和课表数据，不另建一份配置。无数据时使用“未配置”“尚未设置”及对应入口，不用占位数字冒充实际状态。

聊天中的“模型设置”直接定位该聊天正在使用的服务；尚未选择服务时进入模型服务页。页面保留“返回聊天”，返回原对话时保留未发送草稿和原聊天位置。新增或切换服务不自动发送消息。

模型服务和邮箱账号的“保存”与“测试连接”是两个独立操作：保存只保存配置，测试明确发起连接，并说明测试使用当前填写的参数。测试成功不等于已保存，保存成功也不等于连接已通过；不能用同一个成功提示混淆两种结果。已有凭据沿用现有保存与显示方式。

邮箱设置需要独立使用账号配置表单，不能通过挂载整个 `MailPage` 复用界面，以免打开设置就触发收信。关联资料入口跳转到现有资料管理页面，不在设置内复制文件列表、阅读和笔记编辑功能。

学期与节次保存只更新相应配置，保留已有课程、导入来源和其他课表内容。若改动影响课程日期或显示时间，保存处说明实际影响。提醒子页按真实能力展示说明和测试，不增加尚无实现的开关；触发测试提醒后提示已请求系统通知，不能将触发成功写成通知横幅已经送达。

“关于”版本必须来自实际运行应用的版本信息，打包时与应用元数据一致，不能把设计稿中的版本号写成固定文本。数据目录同样读取当前应用实际使用的路径。视觉延续纸感面板、蓝绿点缀和已有深浅色主题，窄窗口依次排列四组入口；返回、保存、取消和测试操作保持清楚可见。

## 本地资料工作区（0.6.0 已实现）

2026-11-07。用户希望在应用内浏览本机文件夹并阅读 Markdown。现有“资料”此前保存关联路径，点击后交给系统应用打开。本轮将它升级为“资料与笔记”中的“本地资料”，让查找文件、阅读原文、询问 AI 和继续记录笔记可以在同一工作台完成。上面的设置总览仍为待实现设计；本节描述已经接入的本地资料功能，最终安装包验证另行记录。

### 浏览与阅读

左侧目录树显示已关联的文件、文件夹与网页链接。文件夹按层展开，每次读取一级目录；超过一页时显示已加载数量、总数和“显示更多”，用户可以继续浏览全部内容。点击文件夹后，右侧显示该目录的完整条目名称；点击 Markdown 或文本则进入阅读。顶部筛选只针对关联资料的名称、路径和分类，不把它表述成全盘文件搜索或全文索引。

阅读器将文件名、相对层级和操作放在正文上方。完整本机路径保存在默认折叠的“文件位置”中，展开后完整显示；文件名和路径换行展示，不使用省略号隐藏内容。正文支持以下操作：

- Markdown 渲染标题、段落、列表、表格、代码块和只读核对清单；“预览／源码”切换可以查看原始内容。
- 文档目录依据实际渲染出的标题生成，点击标题定位正文；代码块中的标题示例不会进入目录。
- 文内查找显示完整匹配数量，支持上一个、下一个和 Enter／Shift+Enter，突出当前命中。
- 相对图片从原文件位置解析并显示；相对 Markdown 链接可跳转到对应文件和标题锚点，网页链接交给浏览器打开。
- “刷新资料”重新读取目录、当前文件及其本地图片，外部编辑后的内容可以立即更新；“用系统应用打开”和“在文件管理器中显示”保留原工具的入口。

应用记住当前文件和展开目录，重新进入后继续浏览。这里保存的是所选文件与目录状态，不承诺恢复正文滚动偏移。课程资料入口带入课程分类；切换分类时清除不属于该分类的当前文件，避免目录显示一门课而正文仍是另一门课。

### 阅读与 AI 的衔接

“询问这份资料”准备一条包含关联项、文件位置和相对路径的可编辑聊天草稿，要求先读取原文件并注明来源。点击入口不发送模型请求，也不自动把正文转存成应用笔记；用户发送后才由现有工作台工具读取。现有输入草稿会保留，资料问题追加到草稿中。

全局搜索中的资料结果现在打开应用内的对应关联项。新产生的文件读取来源保留相对路径，点击引用可定位到实际阅读的文件；旧记录没有相对路径时，继续打开其关联入口。新增关联文件或文件夹后，界面直接定位新条目。

### 产品边界与空间取舍

本地资料以原文件为准，首版只读；备忘录仍使用现有笔记编辑器，两者在标签和保存行为上保持清楚。移除关联只移除入口，不删除原文件。未知格式、文件移动或删除、读取失败都显示可处理的状态，仍提供系统打开或刷新。文本预览支持 8 MB 内文件，超出时说明限制并引导系统打开，不截断正文冒充完整阅读。

独立 PDF 和图片阅读器留待后续需求明确后补充；当前支持 Markdown 中的本地插图。已有 AI 对 PDF 的文字读取能力，不等于本轮已经提供 PDF 页面预览。首版也没有加入原文件编辑、全盘递归扫描或常驻 AI 侧栏，阅读空间主要留给原文；需要讨论时进入既有聊天。

小窗口下隐藏资料页英文眉题，收紧标题、工具栏和阅读器头部的间距，文件区按剩余高度伸展。完整路径默认折叠，文档目录按需展开，正文首块不增加额外顶边距。以上调整只作用于本地资料模式，笔记页面的编辑布局保持独立；具体窗口中的可用高度由桌面验证记录。
