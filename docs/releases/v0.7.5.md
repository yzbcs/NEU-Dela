# NEU Dot 0.7.5

## 1️⃣ 学生类型与课表入口

- 首次启动选择本科生或研究生，设置中的学生类型统一用于课表网页导入、校园入口和 AI 上下文。
- 本科网页导入打开本科教务系统，两类登录会话分别保存在本机。
- 旧版用户升级后确认一次学生类型。

## 2️⃣ 引用文件与 AI 导入

- AI 助手支持引用 PDF、图片和 UTF-8 文字文件，读取结果提供来源。
- PDF 课表固定解析失败后，可携带原文件与失败信息交给 AI。网页采集到表格但识别失败时，可携带表格快照接续。
- 课表识别生成可预览、编辑和确认保存的草稿，星期或节次不确定的课程单列为待确认项。
- 笔记与便利贴新增 AI 导入入口，提示词包含完整读取、已有结果核对、缺项处理和保存验证步骤。
- 新服务默认允许图片输入，旧服务升级时统一开启一次，后续手动关闭可保存。所选模型需要支持对应的图片和工具能力。

## 3️⃣ 聊天界面

- 供应商与模型使用独立选择器，模型列表按当前供应商过滤。
- 对话侧栏按日期分组，支持搜索标题、正文和引用文件，展示供应商与消息数量。
- 聊天标题在本地提炼为简短主题，旧版自动标题升级时整理，后续消息沿用已有标题。

## 4️⃣ 安装与验证

提供 Apple Silicon Mac 的 DMG 与 Windows x64 的 EXE 安装包。两端安装包未签名，macOS 未公证。

Windows 用户先从系统托盘退出应用，再运行新版安装程序，沿用原安装目录及安装范围。工作台数据目录为当前用户的 `%APPDATA%\NEU Dola`，更新前可复制备份。

本地 205 项测试通过，人工页面和模拟模型已验证导入、文件读取、预览保存、供应商选择及标题整理。研究生网页有真实样例验证，本科登录后的真实课表版式仍待验证。当前网页读取依赖 HTML 表格及系统直接域名，其他布局和 WebVPN 代理页面需要进一步适配。Windows 实机登录与覆盖升级仍待验证。
