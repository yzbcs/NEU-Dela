# NEU Dot 0.7.9

本次更新加入 PDF 阅读、划词标注、翻译与 AI 总结，并优化侧栏布局、聊天交互和本地文件访问。

## 1️⃣ 文档阅读与标注

- 在应用内阅读 PDF，支持翻页、缩放和选中文字，单份 PDF 最大支持 50 MB。
- 将 PDF 或 Markdown 文件拖入“资料与笔记”，即可添加并打开。
- 支持四色高亮、批注、编辑、删除和跳转定位，标注独立保存在本机。
- Markdown 相对链接和本地图片通过已添加的文件夹访问，跨分类跳转时自动清除冲突的筛选条件。

## 2️⃣ 阅读时使用 AI

- 选中文字可翻译为简体中文，支持切换模型服务。
- 自动翻译默认开启，选中的英文会发送给所选模型服务，可在阅读工具栏关闭。
- PDF 与文本支持 AI 总结，并显示实际读取范围。单次最多读取 100 页 PDF 或 60,000 字原文。

## 3️⃣ 界面与稳定性

- 主导航栏和资料目录支持调宽、折叠，并记住上次设置。
- 调整首页卡片、按钮和深浅色配色，适配 Windows 标题栏与窗口控制按钮。
- 修复聊天重复发送、切换对话时的附件残留，以及阅读历史消息时被自动滚动打断的问题。
- 改进模型切换、中文输入和弹窗焦点处理，并加强本地文件访问范围校验与存储异常恢复。
