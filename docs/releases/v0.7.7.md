# NEU Dot 0.7.7

应用对外名称更新为 NEU Dot，界面、窗口、系统菜单、托盘、通知和安装包统一使用新名称。

## 1️⃣ 应用内更新

- 启动后自动检查新版本，运行期间每 6 小时检查一次，侧栏和系统通知提示更新。
- “设置 → 关于 NEU Dot”支持手动检查、查看下载进度、取消下载、失败重试及重启安装。
- Windows 通过 NSIS 安装器升级。Mac 在校验更新包、应用标识与版本后替换应用，新版本启动失败时恢复旧应用。
- 安装前保存笔记，进行中的操作与 AI 回复完成后再重启。本地工作台继续沿用原数据目录。

## 2️⃣ 本科课表与交互修复

- 适配本科教务系统的课程卡片和实验课提示框，按实际周次保留教师、地点及节次。
- 支持导入学校导出的 Excel、Word 课表，兼容部分下载文件的错误扩展名，预览提示合并单元格导致的结束节次差异。
- 网页或文件识别失败时，可以携带课程结构和原文交给 AI 继续识别。
- 修复添加邮箱等弹窗中关闭按钮的鼠标交互问题。

## 3️⃣ 安装与升级

0.7.6 及更早版本需要先手动安装一次 0.7.7，后续版本可以在应用内更新。Windows 手动升级前请从托盘退出旧应用，沿用原安装目录及安装范围。

提供 Apple Silicon Mac 的 DMG、升级 ZIP 和 Windows x64 的 EXE，同时发布双平台更新清单及 blockmap。安装包均未签名，macOS 未公证。

本地 248 项测试通过。Mac 隔离环境的完整升级、失败恢复以及笔记与待办保留已验证，本科网页及其 Excel、Word 导出文件已用真实样例核对。Windows 交互式安装和重启升级仍待实机验证。
