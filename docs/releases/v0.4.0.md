# NEU-Dela 0.4.0

面向东北大学（沈阳）学生的本地校园个人工作台，把课表、待办、笔记、邮件与 AI 放在一起。这是本仓库的首个公开发布版本。

## 下载

| 平台                  | 文件                       |
| --------------------- | -------------------------- |
| macOS · Apple Silicon | `NEU-Dela-0.4.0-arm64.dmg` |
| Windows · x64         | `NEU-Dela.Setup.0.4.0.exe` |

安装包位于下方 Assets。macOS 打开 DMG 后将应用拖入 Applications；Windows 运行安装程序并选择安装目录。Intel Mac 与 Linux 暂未提供安装包。

两个安装包均未签名，macOS 未公证，首次打开可能出现系统提示。macOS 可在系统设置的“隐私与安全性”中查看被阻止应用的打开选项；Windows 请核对下载来源与文件名称后再决定是否继续。

## 0.4.0 新增

- **AI 直接完成明确的保存请求**：创建待办、追加课程、保存笔记。每次写入都有真实结果卡，可查看、编辑和撤销。
- **保存结果持续可见**：停止生成、模型后续请求失败与重启不会抹去已保存的结果；同一回复内等价调用不会重复创建。
- **课程追加与冲突提示**：保留原课表、学期与节次，跳过重复安排，标出时间重叠的课程和周次。
- **启动与提醒交互**：品牌启动状态、加载失败重试；点击待办通知定位到记录，并可推迟、完成或恢复。

## 工作台能力

首页汇总未来七天课程与待办；支持全局搜索、研究生课表网页读取、PDF 导入、ICS 导出、重复提醒、笔记本与 Markdown、资料关联、IMAP/SMTP 邮箱，以及浅色和深色主题。AI 支持 OpenAI Responses、Chat Completions 兼容接口与 Anthropic Messages，使用者自行配置模型服务和密钥。

## 验证状态

123 项单元与本机协议测试、生产构建通过；开发版和最终 Mac 包各通过 11 项动作桌面检查，包含重启恢复。Windows 9 项包内资源检查通过，**尚未在 Windows 实机运行**。模型验证使用人工数据与本机模拟服务，不代表真实模型的理解质量；系统通知定位已测，通知横幅送达尚未确认。

## 使用前了解

- 开启工作台连接后，模型会收到为回答问题或执行请求所需的相关工作台内容；关闭后可普通聊天。AI 没有发信工具。
- 研究生课表网页与 PDF 已使用真实样例验证；本科版式待补充。成绩、考试、培养方案和其他个人教务数据尚未接入。
- 提醒依赖应用运行；关闭窗口后托盘仍可运行，退出应用或电脑关机后不提醒。
- 数据保存在本机。请从设置中的“帮助与诊断”打开数据目录；模型密钥和邮箱授权码通过系统加密存储。
