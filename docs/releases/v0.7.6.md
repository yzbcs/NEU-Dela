# NEU Dot 0.7.6

## 1️⃣ 按实际周次处理课程

AI 导入提示补充了周次与教师、教室和时间的对应规则。同一课程第 1–8 周由张老师授课、第 9–16 周由李老师授课时，分别保存两条安排。规则同时覆盖单双周、停课、补课、缺失信息和导入结果核对。

AI 工具支持直接查询第 1–60 周的课程，返回实际适用的教师、地点和时间。日期与周次同时指定时会校验一致性。导入回执同时提供安排条数与不同课程数量。

## 2️⃣ 完善便利贴、笔记与失败接续

- AI 导入便利贴可保存已完成状态，已完成历史记录与活动提醒之间增加一致性校验。
- 提示补充截止时间和提醒时间、重复周期、原文与整理稿、笔记本、同名内容及清单状态的处理要求。
- 长文件和多页 PDF 按实际读取范围继续，部分保存后先核对已成功记录，再处理剩余内容。
- 邮箱和校园查询提示按实际工具能力与读取结果回答。

## 3️⃣ 验证与安装

本地 217 项测试通过，覆盖按周更换教师与教室、单双周、停课补课、完成状态、原文保存，以及三种协议的人工附件导入工具链。提示规则的实际模型遵循情况和真实课表识别质量仍需进一步验证。

提供 Apple Silicon Mac 的 DMG 与 Windows x64 的 EXE 安装包。Windows 用户退出应用后可运行新版安装程序，沿用原安装目录及安装范围。安装包未签名，macOS 未公证。真实本科课表与 Windows 实机升级仍待验证。
