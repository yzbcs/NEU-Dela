# NEU-Dela 0.7.0

设置先显示当前配置，再进入需要修改的项目。聊天可直接按问题使用工作台，无需切换连接状态。

## 本次更新

- **完整设置总览**：通用、模型与连接、学习与提醒、数据与帮助四组，共十个入口。主题、学生身份、模型服务、邮箱账号和学期设置集中管理。
- **配置与测试分开**：模型和邮箱先查看列表，再进入编辑。保存只保留配置；测试使用当前输入，不保存修改，邮箱测试不收取或发送邮件。
- **更自然的返回路径**：聊天中的模型设置定位当前服务，返回后保留未发送草稿。本地资料管理继续进入原文件工作区。
- **学期独立设置**：修改学期名称、首周周一和上课节次时，保留已有课程与导入来源。关于页面显示实际运行的版本。
- **对话直接使用工作台**：移除“工作台已连接”状态与开关，所有对话提供九个工作台工具。普通问候和概念解释可直接回答，工作台问题按需查询；明确要求保存时才创建待办、课程或笔记。
- **统一资料入口**：使用“添加文件夹”“添加文件”和“本地资料”文案。阅读原文件、AI 来源、真实保存结果卡与撤销流程继续保留。

工作台内容会按问题发送给所选模型服务。AI 不发送邮件，也不编辑原文件；模型服务仍需支持工具调用。
