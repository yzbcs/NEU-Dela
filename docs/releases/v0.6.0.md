# NEU-Dela 0.6.0

本地资料现在可以直接在工作台中阅读：打开课程或项目文件夹，查看 Markdown，再围绕当前文件向 AI 提问。

## 本次更新

- **目录与阅读放在一起**：关联文件夹按需逐层展开；Markdown 显示正文、表格、代码块和本地图片，支持相对文档链接、预览／源码切换和文内查找。
- **继续使用原文件**：刷新可读到外部编辑后的内容，支持系统应用打开与文件管理器定位。预览不会改写原文，也不会把文件复制成应用笔记。
- **围绕当前资料提问**：“询问这份资料”准备可编辑草稿，发送后才调用模型。新增的文件读取来源和关联文件搜索结果可在应用内打开对应文件。
- **熟悉的工作台保留**：AI 继续使用 Pi 1.5.0，沿用现有课表、待办、笔记、邮箱、保存回执和撤销。

PDF、Word 等格式暂未嵌入预览，可用系统应用打开；AI 仍支持带文字层 PDF 的按页读取。网络图片显示说明，不自动加载。旧对话未记录的子文件路径无法补回。

## 下载

本版本提供 Apple Silicon Mac 的 `NEU-Dela-0.6.0-arm64.dmg` 和 Windows x64 的 `NEU-Dela.Setup.0.6.0.exe`。安装包未签名，Windows 尚未实机运行。
